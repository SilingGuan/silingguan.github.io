# Siling Guan — Personal Portfolio

Personal portfolio website for Siling Guan, built with React and Vite and deployed through GitHub Pages.

## Built with

- React
- JavaScript / JSX
- Vite
- Lucide React icons
- CSS
- GitHub Actions

## Project structure

```text
.
├── index.html                 # Main HTML entry point
├── package.json               # Project scripts and dependencies
├── vite.config.js             # Vite configuration
├── app/
│   ├── page.jsx               # Portfolio page and React interactions
│   └── globals.css            # Site styling and responsive layout
├── src/
│   └── main.jsx               # Starts and renders the React app
└── .github/
    └── workflows/
        └── deploy.yml        # Builds and deploys to GitHub Pages
```

The live site is:

```text
https://silingguan.github.io
```
